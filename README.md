# Simple Calculator in Python

This is my 1st Python project! It is a basic command-line calculator that can perform addition, subtraction, multiplication, division, and calculate the average of two numbers.

## Features
- Performs basic arithmetic operations:
  - Addition (`+`)
  - Subtraction (`-`)
  - Multiplication (`*`)
  - Division (`/`)
- Calculates the average of two numbers (`avg`).
- Includes basic error handling for division by zero.

## How to Run
1. Ensure you have Python installed on your computer.
2. Clone this repository or download the `calculator.py` file.
3. Open your terminal or command prompt.
4. Run the following command:
   ```bash
   python calculator.py
